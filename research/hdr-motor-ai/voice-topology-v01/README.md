# HDR Voice Topology Lab v0.1 · Speech as geometric form

**Working first experiment, not a new LLM and not a reconstruction of human anatomy.** Inspired by [the 3D wave/gearing machine in `nostack-dev/kurzlernen-de/topology.html`](https://github.com/nostack-dev/kurzlernen-de/blob/main/topology.html). That repository is not modified.

## Hypothesis

Voiced sound arises from periodic vocal-fold excitation, filtered by vocal-tract resonances. Rather than starting with a text token ID, start with the dynamical **acoustic form** associated with a sound. A family of interconnected wave modes might encode useful geometric and topological relationships. We test an initial low-cost geometric representation with explicit simple controls.

### What is implemented

- **Voice → 3D form:** `W(t) = [s(t), s(t+τ), s(t+2τ)]` where τ approximates a quarter of the estimated pitch period. A 3D *delay embedding*, NOT recovered physical XYZ coordinates of pressure or anatomy. Reconstructed points are centred and normalized to RMS radius 1.
- **Six frequency-band wave machines:** each band has its own embedded 3D trajectory and an energy ratio. The correlations between band-energy envelopes are a primitive coupling network.
- **Scale-independent form comparison:** distance-distribution geometry, normalized clique-complex H₀/H₁ Betti signatures across six scales, and group energy proportions.
- **Shape learner:** nearest-template matching against locally saved examples (browser). This is not supervised gradient learning, speech recognition, or language comprehension.
- **Inputs:** reproducible synthetic vowel presets (/a/, /e/, /i/, /o/, /u/) across controllable fundamental pitches, audio-file input, and mobile/desktop microphone input where permission and browser support allow it.
- **No server:** a single HTML file, embedded JS, embedded styles, no CDN. The microphone requires `https://` or localhost.

### Deliberate separation of geometry from physics

A single microphone measurement cannot uniquely reconstruct the 3D pressure distribution or the anatomical topology of vocal cords and vocal tract. Delay embedding represents an observed temporal dynamical system in an abstract 3D phase space. In a future stage, genuinely physical 3D acoustic modeling needs a wave solver plus realistic boundary surfaces or calibrated spatial/multi-sensor observations. **Box3D is a rigid-body dynamics engine; it does not solve the acoustic wave equation.** Using it as if it did would be incorrect. It can still support moving deformable/rigid boundaries in a coupled simulation.

Vocal-fold excitation matters for voiced speech; unvoiced consonants have other excitation mechanisms. A real system must accommodate both.

## Run

Open `dist/index.html` to explore presets or uploaded audio. For microphone, serve over localhost (e.g. `python -m http.server 8080 -d dist`) or HTTPS.

Python experiment:

```bash
python -m pip install -e .
python scripts/benchmark.py
python -m unittest discover -s tests -p 'test_*.py' -v
python scripts/build.py
node --test tests/test_engine.cjs
```

For the optional browser smoke tests, use `python scripts/browser_smoke.py` with Playwright and system Chromium installed.

## Benchmark · synthetic voiced vowels only

`results/benchmark.json` is generated by `scripts/benchmark.py` with three deterministic seeds (12,19,31). Each seed has 20 training and 20 unseen test vowels, with **disjoint fundamental pitches** (train 98–170 Hz; test 205–255 Hz). The target vowel formant template is otherwise unchanged. All models use the same one-nearest-neighbour classifier with feature-wise scaling derived from **training features only**. Lower pitch generalization is not evidence of robustness to speakers, natural consonants or language.

| Representation | Mean held-out accuracy |
|---|---:|
| 3D geometric shape only | 30.0% |
| H₀/H₁ topology only | 48.3% |
| Coupled-group compound feature | 53.3% |
| MFCC spectral baseline | 93.3% |
| Spectral energy ratios (six groups) | 100.0% |

**Negative result is important:** this phase-space shape alone discards acoustic information that simple spectral features capture; adding geometric invariants *currently makes recognition worse*, not better. The compound metric is fixed, not tuned on test. Next meaningful direction is a generative physical model of vocal-tract boundaries and wave propagation whose fitted shape can generalize between excitation pitches.

## Roadmap toward actual world topology

1. Replace the toy synthetic source/filter with measured multi-speaker voiced/unvoiced speech, and evaluate on speakers never seen in training.
2. Implement a lossless baseline and compare 3D waveform phase-space representations with ordinary spectrograms, self-supervised audio embeddings, and spatial microphone arrays.
3. Build a differentiable or gradient-free 3D **acoustic wave solver** with explicit deformable vocal-tract geometry; treat topology of the boundaries separately from topology of the trajectories.
4. Test whether coupled wave structures learn reusable shape, containment, continuity, and deformation invariants on external 3D-world tasks.
5. Only then investigate linguistic composition and generation.

## Current limitations

- Purely simulated/synthetic data for the quantitative benchmark; no human speaker classification claim.
- 3D embeddings are geometric representations of 1D signals, not measured acoustic field coordinates.
- The web engine uses a close but not bit-identical real-time approximation of the Python filtering/resampling chain; values may differ, and benchmark results come from Python only.
- No claim of higher accuracy, lower power, better reasoning, universal topology, or a new LLM.

# HDR Form × Topology — v0.5 falsification experiment

**Verdict:** Local 3D-mesh spring coupling contains useful structural information in this controlled synthetic task, **but it does not beat simple rotation/scale-invariant geometric features**. This is *not* a new general intelligence, not proof of genuine world-topology learning, and not a language model.

## Research question

Can a **mechanically coupled surface-wave machine** discriminate topology / shape under scale, rotation and smooth deformation, and does its *connectivity* matter?

### Inputs

Four closed triangular surface mesh families:

1. `sphere`: one connected genus-0 component, Euler characteristic 2, first Betti number 0;
2. `torus`: one connected genus-1 component, Euler characteristic 0, first Betti number 2;
3. `two_spheres`: two disconnected genus-0 components, Euler characteristic 4, first Betti number 0;
4. `dumbbell`: one connected genus-0 component, Euler characteristic 2, first Betti number 0, **same topology as sphere despite different geometry**.

All examples have exactly **96 vertices**, generated by randomized edge splits preserving the surface's topology, followed by random scale (0.45–2.5), translation, 3D rotation, affine stretches, and smooth non-rigid warps. The train and test specimens have different split patterns and perturbation seeds, and test warps use stronger displacements. Classes are balanced.

### Surface wave system

Nodes correspond to mesh vertices; springs correspond to **actual mesh edges**. Spring constants depend on scale-normalized edge length. A pulse at each of four sample landmarks initiates a damped elastic surface wave:

\[
  \ddot u + 0.12\dot u + 3.2 L_{\mathrm{sym}} u = 0
\]

with explicit symplectic-Euler stepping; `L_sym` is the *weighted, symmetrically normalized graph Laplacian* of the real triangulation. For each pulse, we record time-resolved mean-square displacement and response-frequency band energies. A 3-NN classifier on standardized features predicts the class.

**Important physical caveat:** `u` is a scalar, small-amplitude membrane-wave displacement at each 3D mesh node. This is *not* a full XYZ mass-spring softbody, volumetric acoustic wave PDE or Box3D solver. It is a physical analog on 3D surface adjacency and should not be represented as a complete real-world simulation.

### Control and baselines

- **Shuffled edge endpoints**: geometry and vertex count unchanged, but physically meaningful neighborhoods destroyed; same wave algorithm/readout/classifier.
- **Exact topology**: Euler characteristic + connected components from known, fully observed clean triangle faces. This is an oracle for topology, not a learned model. It cannot distinguish the dumbbell from sphere.
- **Geometry baseline**: quantiles of radial and vertex-pair distances plus covariance eigenvalues; straightforward rotation/scale normalization, same 3-NN classifier.

No label enters the physics, probe selection, or graph construction. All models learn on a training half and are evaluated on the disjoint held-out half. **This is not blind object recognition from real sensors:** full watertight meshes are provided by the generator.

## Reproducible results

36 generated examples per class → **72 train + 72 test** per seed. For seed `20261018`:

| Method | Held-out accuracy |
| --- | ---: |
| Coupled surface waves | **88.9%** |
| Shuffled connectivity control | 54.2% |
| Exact topology only | 75.0% |
| Simple geometric descriptor | **100.0%** |

Across **five disjoint generation seeds**, 360 held-out specimens total:

| Method | Mean accuracy | Min–max across seeds |
| --- | ---: | ---: |
| Coupled surface waves | **86.9%** | 86.1–88.9% |
| Shuffled connectivity control | 64.7% | 54.2–75.0% |
| Exact topology only | 75.0% | 75.0–75.0% |
| Simple geometric descriptor | **100.0%** | 100.0–100.0% |

The gap between coupled and shuffled waves demonstrates that *these features depend on the mesh graph*; it does **not** alone prove generalized topological reasoning (geometric edge lengths and different mesh patterns are also changed). All benchmark examples belong to just four parametrically generated families.

The geometry baseline is perfect on the controlled data, so **there is no empirical advantage over established simple shape descriptors here**. Better tests would involve blind real scans, occlusion, varying sampling density / topology, adversarial near-closed holes, multiple objects in contact, and new object categories never seen in training.

### Run

Python 3.11+ and `numpy`, `scipy`, `trimesh`, `scikit-learn`, `pytest`, `playwright` (browser tests only) with Chromium installed.

```bash
pip install -r requirements.txt
OPENBLAS_NUM_THREADS=1 PYTHONPATH=src python -m benchmark --samples 36 --output results/benchmark.json
OPENBLAS_NUM_THREADS=1 PYTHONPATH=src python src/replicates.py
OPENBLAS_NUM_THREADS=1 pytest -q tests/test_form.py
OPENBLAS_NUM_THREADS=1 pytest -q tests/test_browser.py  # requires Chromium
```

The browser demo is **self-contained** at `dist/index.html` (no CDN). It renders 3D mesh wireframes, responsive wave propagation, topological invariants and live connectivity ablation. Its benchmark figures are frozen data generated by the Python test; moving a slider does **not** retrain the classifier.

### Next valid falsification

Hold out entire *shape construction methods*, not only seeds. Test whether a coupled softbody recognizes topology on meshes with different vertex counts, holes nearly closed, contact changes, noisy 3D scans, and partial observations. Most importantly, compare with geometry and explicit topology algorithms on every such trial. An improvement on a real out-of-distribution task would be meaningful; greater simulation complexity alone would not.
